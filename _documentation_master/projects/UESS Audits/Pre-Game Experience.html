Build & Handoff Notes

Where it lives

This is the Q1-start instance of the defense matchups flow, expanded into a cinematic. It runs on court.html after Set Lineup hands off, before tip-off — replacing (not adding to) the current Q1 popup.

Reuses GET /api/game/{id}/lineup-for-matchups and POST /api/save-man-defense-matchups. No new endpoints.

Suppression contract

Skip Intro jumps past the reveal to the matchups step — submit is still required. Skip state stored per game (pregameSkipIntro_<gameId>) so a mid-game resume doesn't replay it.

The "Don't show again this game" checkbox is the existing one (defenseMatchupsDontShow_<gameId>). Checking it here suppresses the in-game modal at later breaks/timeouts/foul-outs, exactly as today.

Matchups behavior (unchanged)

Drag within your own column to reorder defenders; your defender in slot i guards the opponent at position i. Opponent tile border + connector recolor to the assigned defender's position color.

Matchups still reset to defaults at each subsequent break — this screen only owns Q1.

Audio (your assets)

pregame-regular-season.mp3 plays across the entire pre-game experience — the lineup reveal, the defense-matchups step, and the Tip Off card — then stops as gameplay begins. It must not play during in-game defense-matchups modals.

Cue markers (toggle above) show SFX layered on top of the track: a click-beep as each of the 5 matchups lands. Gameplay BG music starts when the Tip Off card auto-dissolves.

Cards & tokens

Player tiles reuse the Scouting card DNA: headshot, position badge, name (#jersey), HT·WT·YR, RT, and PPG/RPG/APG/DEF%. RT color follows the canonical Attribute Bar Scale (81+ blue, 61–80 green, 41–60 yellow, ≤40 red). Class year is always the 2-letter form.

Images via getPlayerImageUrl(player_id, {size:'card'}); both teams have images. Placeholders shown here.

Stat source differs by context: the pre-game overlay shows season stats (PPG/RPG/APG/DEF%). Every in-game defense-matchups instance (quarter breaks, timeouts, foul-outs) must wire these same fields to current-game stats instead.

Accessibility / perf

prefers-reduced-motion skips straight to the settled board (no reveal animation). All images lazy + explicitly sized. Runs entirely on data already fetched for the matchups popup — no added load.
