# Development Status — Active Task Board

Lightweight handoff tracking for GOB workstreams. This file shows the **single current in-action task** per bucket so Lobot (Jamie's CoS bot), coding agents (Cursor/Claude/Codex), and humans can quickly see what's actively being worked on right now.

**Purpose:** Real-time status visibility for active work only. The comprehensive backlog remains in `bugs.md`.

## How to Update

- **Keep to one in-action task per bucket** — what is actively being worked on right now, not what's queued
- **Set to `N/A`** when a bucket is idle (no active work)
- **Update when starting work** — set your task as the Current task
- **Update when finishing work** — clear to `N/A` or hand off to the next task
- **Update the Last updated date** — use ISO 8601 format (YYYY-MM-DD)
- **Owner/agent is optional** — use to clarify who/what is executing (human name, "Cursor", "Claude", etc.)

**Note:** This is the live board. Full backlog, priorities, and details live in `bugs.md`. Don't duplicate backlog here.
