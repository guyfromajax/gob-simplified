##Objective
Add more readable drama and excitement to the Sim Full Game / Sim Rest of Game (called "Sim Game Exmperience" in the rest of this doc) Experience.

Note user behavior is showing this may very well be the most imporant screen in the game -- in addition to FCC. Most users are simming games rather than playing the with full Turn By Turn experience. So it's important we nail this. This screen will probably end up being the face of the GOB brand.

##Task
Leverage both world-class UX design practices and principles as well as consider some creative new idea to make this a premium, dynamic, intuitive, and exciting experience for the user without overwhelming them with too much info.

##Informoation that must be present
1. Scoreboard (current version, as is)
2. Game score worm (currently version working nicely but open to tweaking if that is better for the overall UX).
3. Current active lineups for both teams, core 4 stats for active players (points, rebounds, assists, DEF%), and a visual handle for those stats (right now the green/blue pill fill bars are working well, but open to other formats that are more interesting, dynamic, or better fit our overall UX)
4. Also need to dispaly the fouls, foul trouble, and hot/cold info that is currenlty wired. Also need to preserve the "Top" for the top player on the court -- that is a nice feature.
