In-Game Modal — Notes

Same, but contained

Identical card DNA and matchup logic as the pre-game overlay — headshots, RT badge, favorability arrows, team-color borders, drag-to-reassign — inside the Strategic Modal footprint (max ~1000px, rgba(18,22,32,0.98), no cinematic reveal). No full-screen takeover mid-game.

Current-game stats

The four stat fields are wired to current-game values (PTS / REB / AST / DEF% this game), not season. Pre-game overlay uses season; every in-game instance uses game stats.

Behavior unchanged

Fires after "Play Quarter" at quarter breaks, timeouts, foul-outs. Backdrop does not dismiss. Submit (green, gating) saves via /api/save-man-defense-matchups. "Don't show again this game" suppresses the rest of the game via the existing sessionStorage flag; matchups reset to defaults each break.

Team headers (dynamic)

Both the team names and the role labels are data-driven: the user's team always occupies the left "Your defense" column, the opponent the right "Offense" column. Column headers use the team-color tint from the styleguide (rgba(color,0.2) fill, rgba(color,0.6) border). Team primaries are placeholders here.
