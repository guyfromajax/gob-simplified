Part 2 · Browse templates

Page tools

Right end of the sticky sub-tab row (no extra sticky height). Segmented scope · search. Neutral selection — navy stays reserved for your own row.

Table (T1)

Header 34 · row 40 (×1.18 at 1920). Numbers right-aligned, tabular. First header cell names the group so it stays visible while stuck. Sort indicator is neutral (▾/▴ + 2px w-70 underline); the sorted column gets a w-3 wash.

Empty and loading

No spinners. Loading keeps the real header and draws neutral skeleton bars in the final shapes (row count = expected rows, capped at the viewport). Pulse: opacity 1 → .45, --dur-skeleton 1.4s; off under reduced motion.

Wide table · horizontal scroll inside its own card

Only when a table is genuinely wider than the page (League › Team Stats at 1280). The header does NOT stick (it is inside an overflow container); instead it repeats every 16 rows. The team column pins left. Edge fades show there is more; the card header carries group jumps, a position map and ◂ ▸ paging (80% of the visible width). Shift+wheel / trackpad scroll horizontally. The page keeps its one vertical scroll.

Leaders board (T1 variant)

8 category cards, 4 × 2 at 1280. Leader block + ranks 2–5 + “Full list →” (opens the category as a T1 table). Your players carry the navy row.

Attribute grid (T2)

Attributes are a single digit = floor(raw/10), no cap. Hue on the glyph = tier (0–4 red · 5–6 yellow · 7–8 green · 9+ blue). Behind it, neutral luminance by tier (none · w-3 · w-6 · w-10 + ring) so strengths read as bright blocks and weaknesses recede — without spending hue on a fill. Pairs are grouped under OFFENSE · DEFENSE · SKILLS · GRIT · BODY · MIND with a group-start rule and alternate-group banding.

Team measures (Team › Team Attributes)

Name + one-line “what it drives” · value / scale · neutral meter · weekly delta chip. Only movers get a coloured chip; flat is “—”.

Detail page (T3)

Third level only (player / team / recruit). Sticky bar: “up one level” back (goes to the list the user came from, restoring its scroll, sort and scope) + breadcrumb + prev/next within that list. Hero: identity + RT letters + key numbers. Body: sectioned cards, no tabs, one page scroll.
