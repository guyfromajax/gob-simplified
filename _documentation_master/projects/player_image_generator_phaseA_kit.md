## 1. Body archetype system (9-grid)

Every player classifies by two axes from their height + weight:

| | **Lean** (bottom BMI third) | **Normal** (middle third) | **Strong** (top third) |
|---|---|---|---|
| **Short** (<72") | S-Lean | S-Normal | S-Strong |
| **Normal** (72–78") | N-Lean | N-Normal | N-Strong |
| **Tall** (≥79") | T-Lean | T-Normal | T-Strong |

**Build is height-adjusted (BMI), not raw weight** — otherwise a 6'10"/210 lb player reads "strong" when he's actually lean. Cutoffs are the **tertiles of the real player population** (so each build class holds ~1/3 of players). Provisional cutoffs are in `scripts/classify_player_archetypes.py`; replace them with the real numbers the export script prints.

**Two layers, different granularity:**
- **Prompt/classification layer → use all 9.** Height drives face maturity + overall scale; build drives the body descriptor. This is where the variety lives.
- **Uniform template layer → build only 3 (the build axis) to start.** The portrait is shoulders-*up*, so height is cropped out — the jersey template keys on **shoulder width = build**. Build one parametric template each for Lean / Normal / Strong, recolored per team from the DB. Split toward more templates only if QC shows a tall torso genuinely doesn't sit right.

Run `python3 scripts/classify_player_archetypes.py` to classify any roster.

## 5. Bake-off (Phase A gate)

**Generate the same 3 players in all three tools** — chosen to span ethnicity, build, and height:

| Test player | Archetype | Tests |
|-------------|-----------|-------|
| Stanley Keith (#4) | N-Strong, Black | dark skin, broad build, the locked anchor's own tone |
| Colt Robles (#27) | S-Lean, Hispanic | medium skin, lean guard build |
| Eugene Johnston (#46) | T-Strong, White | fair skin, tall/big — the hardest case + the reference gap |

Max 2 attempts per player per tool (tweak only the player line). Then **view all 9 outputs next to real Conf1 masters at 256px** (roster-thumbnail size — that's where they'll actually live).

**Score each output 1–5:**

| Criterion | What you're checking |
|-----------|----------------------|
| Style match | Semi-realistic painted finish — not photo, not cartoon, not "AI portrait" |
| Lighting | Soft frontal studio light like Conf1 |
| Framing | Shoulders-up, centered, head scale consistent with Conf1 |
| Skin rendering | Smooth gradients, no plastic sheen or pore-level photo detail |
| **256px believability** | Sits in a roster grid next to Conf1 without looking imported *(the money test)* |
| White-tank clean | No logos/text/color bleed on the jersey |
| Cutout ease | How clean is the transparent-bg result / how hard to `rembg` |

Also record the **practical** per tool: has an API? cost per keeper? attempts to get a usable image? Sum the scores, weight the 256px row heavily, and **lock the winner + the exact prompt/ref recipe** before Phase B.
