THREE SEGMENTS PER ROW

Identity and readiness (headshot, name, energy) — then production — then status (RT, F, MIN, MO). The stats cluster carries 26px of breathing room on both sides, so the row reads as three groups rather than nine columns.

THE POCKET IS NOW THE ACTION ZONE
