**The comments, in code rather than only here:**
- **`calc_skeleton_step_timing_contract`** (`BackEnd/utils/shared.py`): the whole-second rounding and the 1 s floor inflate the contract by ~3.33 s/turn (9.43 rounded vs 6.10 unrounded), while sim is separately missing ~5.18 s/turn that played burns — entry orchestration ~3.15, post-shot sub-steps ~1.03 (now supplied by `GOB_SIM_CRASH_CLOCK`), per-step model ~1.0. **The rounding is standing in for the missing entry time and the two nearly cancel**, so removing the rounding alone makes the arm gap sharply worse, and entry orchestration must not be added without removing the rounding in the same change. It also records that the gate set explains only −0.13 s/turn. Cites `reports/clock-and-crash-scope-2026-09-17.md` §A2.
- **`sim_post_shot_window_seconds`**: derived/emitted window ratio **0.80 on a miss, 0.57 on a make, 1.62 on a block**, with overall position accuracy against played of **2.17 units mean** (0.81 on misses, 3.66 on makes, 13.31 with the write disabled). Flags the make case as the systematically wrong one and warns that tightening it also moves the sim clock.

## Which footing is production?

**`SEED_DEFENSES=1`.** It seeds the six real defense documents from `defenses_export.json`, which is a verbatim copy of `gob-staging.defenses` and matches `gob`. With the catalogue present, `is_zone_defense` resolves, zone calls are played as zones, and about half of all half-court possessions run a real 2-3 / 3-2 / 1-3-1 shell — which is what a production game does.

`SEED_DEFENSES=0` leaves `defenses_collection` empty, which is a harness artefact, not a game state: `defense_identity` reports the catalogue as `empty`, every zone call is substituted with man placement, and `[DEFENSE-IDENTITY SUBSTITUTION]` fires on ~2,500 possessions a game. It is kept only as a control against the older baselines that were cut that way. **Tune against the `SEED_DEFENSES=1` column.**
