## Summary

Scouting Report is a registered module view `#scouting-view` in the Prep shell. `?tab=coaches-tab` and legacy `#coaches-tab` canonicalize to `scouting-view`. Prep underline opens **Scouting Report** → `scouting-view`.

The old `#coaches-tab` FCC card stack (radar, side cards, P5 photo cards) is removed from the Prep path. **`buildTeamMeasuresRadarMarkup` remains** in `franchise-command-center.js` for the **Team Measures** summary on `#team-stats-tab` / `#team-measures-radar` (user team), not for Prep scouting.

Data: `GOBFccPrep.whenReady()` → opponent via existing `resolveUpcomingOpponentFromMatchup` → parallel `GET /franchise/team-data` (prefer `team_id`) and `GET /franchise/scouting-report`. Header ranks use `measures[]` (Shooting, Rebounding, Chemistry): ordinal rank + percentile bar, UX §15 style (`12th of 128`, no T-). Eight diverging measure rows use neutral `.ms` / `.dv` (no strongest/weakest, no `.hi`). Projected five uses T2 `.agrid` with Attributes/Stats toggle and existing stats columns via `scoutingReport.js`. Usage tables reuse `renderPlayUsage` client maths and Film Study lock copy.

New assets: `scoutingView.js`, `css/gob-browse-templates.css`, `css/prep-v2.css`, `css/prep-v2-scouting.css`, `tests/e2e/prep-scouting.spec.js`.
